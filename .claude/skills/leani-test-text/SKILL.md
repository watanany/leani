# テストの文の見直し

集める段と確かめる段はスクリプトで行い、判断する段だけを AI が行う。

## 1. 集める (スクリプト)

```
just texts
```

`main-rs` から足した `ja:` と `en:` の行を、`ファイル:行: 文` の形で出す。
見直すのは、この出力に出た行だけにする。

## 2. 判断する (AI)

`DEVELOPMENT.ja.md` の「テストの文の書き方」を読んでから、出力の行ごとに、テストの中身 (assert) と照らして判断する。
次の表の形だけで答える。

| 場所          | 判定     | 理由                        | 直した文      |
| ------------- | -------- | --------------------------- | ------------- |
| `ファイル:行` | OK か NG | NG のときだけ、破った決まり | NG のときだけ |

見る点は次のとおり。

- ja: Given / When / Then の順に読めるか。テストが確かめていないことを書いていないか
- en: Then の動詞 (3 人称単数) から始まり、ja の訳になっているか。`glossary.toml` の語を使っているか

## 3. 確かめる (スクリプト)

NG の文を直したら、次を実行する。

```
cargo run -p spec
cargo run -p spec -- --check
```

ja の文は、スキル `yomiyasu` の lint にもかける。「半角」と「空白」の指摘は無視し、半角の () は残す。
