# Jupyter で使う

leani は Jupyter のカーネルとしても使える。
ノートブックのセルには、端末の leani に入力するのと同じ内容を書く。
補完、エンジンが異常終了したときの復帰、証明モードも、端末と同じように使える。

## インストール

次のコマンドで、Jupyter 用の依存パッケージと一緒に leani をインストールし、カーネルを登録する。
leani をすでにインストールしている場合は、`uv tool install` に `--reinstall` を付ける。

```
uv tool install 'leani[jupyter] @ git+https://github.com/watanany/leani'
leani --install-kernel
```

`leani --install-kernel` は、ユーザーの Jupyter に「Lean 4 (leani)」というカーネルを登録する。
登録したカーネルは、leani とは別にインストールした JupyterLab からも使える。
JupyterLab が無い場合は、`uv tool install jupyterlab` でインストールできる。

## セルの書き方

leani は、セルの各行を端末で入力したときと同じ順に読み、セルの終わりで入力を確定する。
1 つのセルに複数の宣言を書いてもよい。
`:t` や `:prove` などのコマンドもセルに書ける ([コマンド](usage.md#コマンド) を参照)。

```
def fib : Nat → Nat
  | 0 => 0
  | 1 => 1
  | n + 2 => fib n + fib (n + 1)

#eval fib 10
```

証明モードでは、`:prove` のセルを実行したあと、タクティクを 1 つずつ別のセルに書く。
証明が完了すると、leani は `sorry` を証明に置き換えた宣言を環境に追加する。

エラーがあったセルは、実行結果がエラーになる。
そのため、「すべてのセルを実行」はエラーのセルで止まる。

カーネルは、ノートブックのあるディレクトリで起動する。
Lake プロジェクトの中にあるノートブックでは、端末の leani と同じく、そのプロジェクトの環境で起動する。
leani は最初のセルを実行するときにエンジンを起動するので、最初のセルは時間がかかる。

`:q` は、セルに書いても何もしない。
カーネルを終了するには、Jupyter のメニューからカーネルを終了する。

## 補完

名前を 2 文字以上書いてから Tab を押すと、leani は定数名を補完する。
最初のセルを実行するまではエンジンが起動していないので、補完の候補は表示されない。

`\to` のように略記を書いてから Tab を押すと、leani は略記を記号に置き換える。
JupyterLab には space で略記を置き換える機能が無いので、端末と違って Tab を使う。

## 中断とエンジンの異常終了

Jupyter の中断ボタンで評価を止めると、leani はエンジンを再起動して、実行済みの宣言を再実行する。
エンジンが異常終了した場合も同じである。
どちらの場合も、次のセルではそれまでの宣言を使える。
中断したセルの実行結果はエラーになる。
