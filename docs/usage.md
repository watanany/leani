# 使い方

## 機能

- **複数行の入力**：leani は、入力が終わったかを Lean のパーサで判定する。インデントした行か `|` で始まる行が続くあいだは入力を読み続け、空行で入力を確定する。確定した直後にインデントした行を書くと、leani は直前の入力とその行をつなげて、1 つの入力として読み直す
- **式の評価**：式だけを書くと、leani は `#eval` で評価する。評価できない式 (`Real.pi` など) は `#check` で型を表示する
- **宣言**：宣言にエラーがあると、leani はその宣言を環境に追加しない
- **エラーの表示**：leani はエラーの行を表示し、エラーの位置に `^` を付ける
- **補完**：2 文字以上入力してから Tab を押すと、leani は定数名を補完する。REPL で実行した宣言の名前や、`open` した名前空間の短い名前も補完の候補になる
- **略記の入力**：`\to` と入力して space を押すと、leani は `\to` を `→` に置き換える。同じように、`\all` は `∀` に、`\dot` は `·` に置き換える。表記は VS Code の Lean 拡張と同じである。leani は、Tab では略記を置き換えない (Tab は補完に使う)
- **履歴**：Ctrl-P を押すと、前の入力を呼び出せる。複数行の入力も 1 件として呼び出せる。履歴は次のセッションにも引き継がれる
- **証明モード**：`sorry` のある定理を書いた直後に `:prove` を実行すると、タクティクを 1 つずつ試せる ([証明モード](#証明モード) を参照)
- **init ファイル**：leani は起動時に init ファイルの宣言を実行する (詳しくは [設定](config.md#init-ファイル) を参照)

## エンジンが異常終了したとき

評価中に Ctrl-C を押したときや、エンジンが異常終了したとき、leani はエンジンを再起動して、実行済みの宣言を再実行する。
再実行に失敗した宣言は **保留** になる。
leani は保留中の宣言を環境に追加しないが、削除せずに残しておく。
保留中の宣言は、次の `:restart` で再実行される。
`:reset` と、成功した `:l` は、保留中の宣言を捨てる。

エンジンを再起動できなかった場合、leani は入力も `:reset` も受け付けない。
原因を直してから `:restart` を実行する。

`:env <name>` で環境を切り替えると、leani は実行済みの宣言と保留中の宣言を、切り替え先の環境で再実行する。
切り替え先の環境で起動できなければ、leani は元の環境に戻る。

## コマンド

REPL の中で `:help` を実行すると、同じ一覧を確認できる。

| コマンド           | 説明                                                                                                       |
|--------------------|------------------------------------------------------------------------------------------------------------|
| `:t <expr>`        | 式の型を表示する (`#check`)                                                                                |
| `:i <name>`        | 型と docstring を表示する                                                                                  |
| `:p <name>`        | 定義を表示する (`#print`)                                                                                  |
| `:loogle <q>`      | 定理を検索する。leani は外部の loogle サービスに問い合わせるので、ネットワークが必要。検索の対象は Mathlib |
| `:l <file>` / `:r` | ファイルを読み込む / 読み込み直す。実行済みの宣言は捨てる。init ファイルの宣言は残る                       |
| `:reset`           | 実行した宣言をすべて取り消し、起動直後の状態に戻す (`:l` したあとは、読み込んだ直後の状態に戻す)           |
| `:undo [n]`        | 直前の n 件の宣言を取り消す (n のデフォルトは 1)                                                           |
| `:env [name]`      | 今の環境を表示する / 設定した環境に切り替えて再起動する                                                    |
| `:prove [n]`       | 直前の入力にある n 番目の `sorry` について、証明モードを始める (n のデフォルトは 1)                        |
| `:goals`           | 残っている `sorry` とゴールを表示する                                                                      |
| `:save <file>`     | 実行した宣言を `.lean` ファイルに書き出す                                                                  |
| `:time`            | 実行時間の表示を切り替える                                                                                 |
| `:restart`         | エンジンを再起動して、宣言を再実行する                                                                     |
| `:{ ... :}`        | 複数行を明示的に囲む                                                                                       |
| `:! <cmd>`         | shell のコマンドを実行する。Ctrl-C で止めても leani は終了しない                                           |
| `:help` / `:?`     | コマンドの一覧を表示する                                                                                   |
| `:q`               | leani を終了する (Ctrl-D でも終了する)。証明モードの中では、証明モードを終了する                           |

`:loogle` には、名前 (`Nat.succ_le`)、型 (`(?a -> ?b) -> List ?a -> List ?b`)、結論 (`|- ?a + ?b = ?b + ?a`)、名前に含まれる語 (`"commutative"`) のどれかを渡す。

`:save` は、すでにあるファイルには書き込まず、`すでにある` と表示する。
ただし、同じセッションで `:save` したファイルには上書きする。
書き出すファイルには、init ファイルと `:l` したファイルの宣言、`:l` したファイルの `import` も含まれる。
保留中の宣言は、コメントとして書き出す。
書き出したファイルは、`:l` でも `lake env lean` でも読み込める。

## 証明モード

証明モードでは、1 回の入力が 1 タクティクになる。
証明モードの中では、次のコマンドを使える。

| コマンド | 説明 |
|----------|------|
| `:goals` | ゴールを表示する |
| `:script` | ここまでのスクリプトを表示する |
| `:undo` | 直前のタクティクを取り消す |
| `:done` | 証明モードを終了する |

```
λ> theorem tt (n : Nat) : n + 0 = n := by sorry
sorry 1 [proofState 0]
  n : Nat
  ⊢ n + 0 = n
-- :prove で証明モードを始められる (sorry 1 個)
λ> :prove
証明モード: 1 行が 1 タクティク。:goals ゴール  :script スクリプト  :undo 取り消す  :done 終了
goal
  n : Nat
  ⊢ n + 0 = n
⊢> induction n with
 |   | zero => rfl
 |   | succ k ih => simp
 |
証明完了。
-- スクリプト:
  induction n with
    | zero => rfl
    | succ k ih => simp
-- sorry をスクリプトで置き換えて実行する:
  theorem tt (n : Nat) : n + 0 = n := by
    induction n with
      | zero => rfl
      | succ k ih => simp
λ> #print axioms tt
'tt' depends on axioms: [propext]
```

証明が完了すると、leani は選んだ `sorry` をタクティクで置き換えた宣言を実行し、元の宣言と差し替える。
ほかの `sorry` はそのまま残る。
`exact?` や `simp?` を使うと、leani は `exact?` や `simp?` の代わりに、Lean が提案したタクティクをスクリプトに記録する。

## 起動オプション

`leani -h` を実行すると、すべてのオプションを確認できる。

```
leani                  # デフォルトの環境で起動する
leani -e math          # 設定した環境を名前で選ぶ
leani -p . -i MyLib    # 設定の環境を使わずに、Lake プロジェクトと import を指定する
leani foo.lean         # ファイルを読み込んで起動する
leani --setup          # エンジンを用意して終了する
leani -V               # 環境、Lean のバージョン、ファイルの場所を表示する
```

`-i` は繰り返して指定できる。
`-i` を付けると、leani はプロジェクトの `lean_lib` を import せず、`-i` で指定したモジュールだけを import する。
leani は、設定やオプションに関係なく常に `Lean` を import する。
環境とデフォルトの決まり方は [設定](config.md) を参照。
